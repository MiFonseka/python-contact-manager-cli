# python-contact-manager-cli
Simple command-line contact manager built with Python. Allows adding, viewing, searching, and deleting contacts with data stored in a JSON file.

# Contact Manager CLI (Python)

A simple command-line contact manager built with Python.

## Features
- Add contacts
- View all contacts
- Search contacts
- Delete contacts
- Persistent storage using JSON

## Technologies Used
- Python
- JSON (for data storage)
